# Reconstructed 28x28 grayscale class images

Each ZIP contains PNG images in grayscale, arranged in a class-named folder. The images were reconstructed from the labeled pixel rows in `../lbddataset.csv`; these are processed 28x28 representations, not original-resolution chest X-rays.

Class folders and image counts:

- `Normal.zip`: 3,500
- `TB.zip`: 700
- `Pneumonia.zip`: 3,875
- `COVID.zip`: 3,616

Total: 11,691 images. The source file contains 11,691 labeled rows, nine fewer than the 11,700 stated in the project description.
