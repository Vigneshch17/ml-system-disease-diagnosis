# Dataset files

- `lbddataset.csv`: labeled 28x28 pixel-feature table used by the project. It contains columns `D1` through `D784` and `DISEASE`.
- `grayscale_pixels_28x28.csv`: 28x28 pixel values per row (784 values), without labels.

These are processed grayscale pixel tables, not the original X-ray image files. Original images were not present in the local project folder when these files were prepared. The other 32x32 and 64x64 exports are not included here.
